Batch 1 sedang berjalan · gratis

Belajar coding sampai benar-benar selesai, didampingi engineer sungguhan.

Kenapa kelas ini

Kebanyakan orang berhenti belajar coding bukan karena kurang materi.

Mereka berhenti karena stuck sendirian, tidak ada yang menagih, dan tidak pernah menyelesaikan apa pun. Sekarang AI bisa menjelaskan apa saja, tapi AI tidak akan bertanya minggu ini kamu sudah sampai mana. Kelas ini dibangun untuk menutup celah itu.

// mentor

Diajar engineer yang sehari-hari membangun aplikasi

Bukan pengajar yang hanya membaca slide. Contoh dan cara berpikir diambil dari pekerjaan nyata.

// akuntabilitas

Ada yang memastikan kamu sampai garis akhir

Check-in mingguan, feedback pada kodemu, dan demo day di minggu terakhir. Kamu tidak dibiarkan menghilang di minggu kedua.

// project

Pulang membawa project yang kamu pahami

Ukuran berhasilnya adalah kamu bisa menjelaskan cara kerja programmu sendiri, bukan jumlah video yang ditonton.

// AI

Belajar memakai AI tanpa jadi bergantung

AI masuk kurikulum sebagai asisten: untuk memahami kode dan melacak error, sambil tetap melatih logikamu sendiri.

Perbandingan bersifat umum. Biaya dan fitur kursus maupun bootcamp berbeda-beda di tiap penyedia.

Yang kami janjikan

  • Kelompok kecil, supaya setiap peserta mendapat perhatian
  • Feedback pada kodemu, bukan hanya materi
  • Target yang jelas: satu project selesai dan bisa kamu jelaskan
  • Hasil setiap batch dipublikasikan apa adanya: berapa yang menyelesaikan project dan apa saja yang mereka bangun

Yang tidak kami janjikan

  • "Pasti jadi programmer dalam 5 minggu"
  • "Pasti dapat kerja"
  • Jalan pintas tanpa latihan. Tetap perlu waktu belajar setiap minggu.

// pemula & career switcher

Ingin pindah jalur atau mulai dari nol

Tidak perlu latar belakang IT. Cocok kalau kamu sudah pernah coba belajar sendiri tapi selalu berhenti di tengah jalan.

Mau memperkuat skill teknis

// penasaran soal AI

Ingin memakai AI secara praktis

Belajar memakai AI untuk memahami kode dan mencari penyebab error, sambil tetap paham apa yang kamu tulis.

Yang kamu butuhkan: laptop atau komputer, Chrome atau Firefox, akun Discord, dan sekitar 30–60 menit latihan mandiri per minggu.

Kurikulum Batch 1

Lima minggu, satu konsep demi satu konsep.

Setiap minggu punya pola yang sama, jadi kamu selalu tahu apa yang akan terjadi di kelas.

Penjelasan konsep→Live coding mentor→Praktik bersama→Latihan mandiri→Check-in Discord
Minggu01

Kenalan dengan programming

Cara berpikir komputasional, program pertama, variabel, tipe data›

Yang dipelajari

  • Apa itu programming dan kenapa komputer butuh instruksi yang jelas
  • Memecah masalah jadi langkah-langkah kecil
  • console.log(), const vs let
  • String, number, boolean

Tugas Discord: kirim kode ke #weekly-progress, ceritakan konsep baru yang kamu pelajari dan bagian yang masih membingungkan.

let score = 10;
score = 20;
console.log(score); // 20

const isAvailable = true;
Minggu02

Operator, kondisi, dan loop

Program yang bisa menghitung dan mengambil keputusan›

Yang dipelajari

  • Operator matematika dan perbandingan, kenapa ===
  • if / else untuk mengambil keputusan
  • Loop for: nilai awal, kondisi, increment
  • Live coding: kalkulator diskon

Latihan: tampilkan angka 1–10. Tantangan: hanya angka genap, lalu hitung totalnya.

const price = 150000;
const discount = 20;
const finalPrice = price - price * discount / 100;

if (price >= 100000) {
  console.log("Harga setelah diskon:", finalPrice);
}
// Harga setelah diskon: 120000
Minggu03

Function, array, dan debugging

Kode yang bisa dipakai ulang dan mengolah kumpulan data›

Yang dipelajari

  • Function, parameter, argument, return
  • Array dan indeks yang dimulai dari 0
  • Membaca pesan error dan memperbaiki kode bertahap

Tugas Discord: kirim function buatanmu dan satu contoh error yang berhasil kamu perbaiki.

function calculateTotal(price, quantity) {
  return price * quantity;
}

console.log(calculateTotal(25000, 3));
// 75000
Minggu04

Mini project: pencatat pengeluaran

Menggabungkan semua konsep jadi satu program›

Yang dibangun

  • Data pengeluaran sebagai array of object
  • Menampilkan daftar dan menghitung total
  • Peringatan saat melewati batas anggaran
  • Satu fitur tambahan pilihanmu sendiri

Satu fitur tambahan yang benar-benar dipahami lebih baik daripada lima fitur hasil copy-paste.

const expenses = [
  { name: "Lunch", amount: 25000 },
  { name: "Transport", amount: 15000 },
  { name: "Coffee", amount: 20000 }
];
Minggu05

Demo project dan mengenal AI

Presentasi singkat, lalu AI sebagai coding assistant›

Demo 3–5 menit, tanpa slide formal

  • Masalah yang ingin diselesaikan
  • Cara program bekerja dan konsep yang dipakai
  • Kesulitan yang kamu hadapi
  • Fitur yang ingin dikembangkan berikutnya

Praktik AI

  • Minta AI menjelaskan kodemu, lalu bandingkan dengan pemahamanmu
  • Minta satu ide fitur baru, lalu putuskan sendiri apakah kamu mampu membuatnya
Project akhir

Pencatat pengeluaran yang kamu tulis sendiri.

Bukan aplikasi full-stack dulu. Program sederhana di browser console yang kamu pahami dari baris pertama sampai terakhir.

  1. Menyimpan daftar pengeluaran
  2. Menampilkan setiap pengeluaran
  3. Menghitung total pengeluaran
  4. Memberi peringatan jika melewati batas anggaran

Fitur tambahan pilihan: menambah pengeluaran baru, rata-rata pengeluaran, pengeluaran terbesar, atau kelompok per kategori. Coba versinya di samping.

    FAQ
    Pertanyaan yang sering muncul
    
      
    
        
    Materinya kan sudah banyak gratis di YouTube. Kenapa ikut kelas?
    Benar, materinya ada. Yang tidak ada di video adalah orang yang melihat kodemu, menjawab pertanyaanmu yang spesifik, dan menagih progresmu setiap minggu. Kelas ini membantumu menyelesaikan apa yang kamu mulai.
    
        
    Bukankah sekarang sudah ada AI yang bisa mengajari coding?
    AI sangat membantu, dan kita memakainya di kelas. Tapi tanpa fondasi, kamu tidak bisa menilai apakah jawaban AI benar. Di sini kamu belajar dasarnya dulu, lalu memakai AI sebagai asisten yang kamu pahami.
    
        
    Saya benar-benar belum pernah coding. Bisa ikut?
    Bisa. Kurikulum ini dirancang untuk orang tanpa pengalaman coding, termasuk yang tidak punya latar belakang IT.
    
        
    Perlu install software?
    Tidak untuk awal. Kita praktik langsung di browser console (Chrome atau Firefox). Kalau ingin workspace yang lebih nyaman, kamu bisa memakai editor online seperti JSFiddle atau CodePen.
    
        
    Kenapa JavaScript?
    JavaScript bisa langsung dijalankan di browser tanpa instalasi, jadi kamu bisa fokus belajar cara berpikir programming sejak hari pertama. Bahasa ini juga jadi dasar yang baik untuk lanjut ke web development.
    
        
    Berapa waktu yang perlu saya sediakan?
    Satu kelas live 90 menit per minggu, ditambah sekitar 30–60 menit latihan mandiri dan check-in di Discord.
    
        
    Apakah setelah ikut saya pasti jadi programmer atau dapat kerja?
    Tidak ada janji seperti itu. Targetnya realistis: kamu memahami fondasi JavaScript, menyelesaikan satu program sederhana, dan cukup percaya diri untuk lanjut belajar sendiri.
    
        
    Bagaimana cara ikut batch berikutnya?
    Pendaftaran Batch 1 sudah ditutup. Batch berikutnya akan diumumkan lewat Threads dan kanal #announcements di Discord, lengkap dengan formulir pendaftaran.
